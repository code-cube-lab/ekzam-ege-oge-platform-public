# «ЭКЗАМ» — школа подготовки к ОГЭ и ЕГЭ

Рабочий модуль будущей мультипредметной платформы: отдельный вход в ОГЭ или ЕГЭ, полноценные русские варианты и стартовые авторские банки по 15 предметам. AI является помощником преподавателя, а не самостоятельным источником экзаменационных правил.

## Уже работает

- лендинг, кабинет ученика и кабинет преподавателя;
- серверная диагностика и защищённые состояния доступа;
- Telegram-бот с последовательным выбором `ОГЭ/ЕГЭ → предмет`, командами полного варианта, задания дня и тетради ошибок;
- Telegram Mini App с разделами «Сегодня», «Вариант», «Ошибки», «Профиль» и 15 предметами ЕГЭ / 14 предметами ОГЭ;
- ежедневное микро-задание, адаптация по ошибкам, освоение темы и дата повторения;
- открытый урок по циклу `видео → объяснение → задание → разбор`;
- четыре уровня: стартовый, базовый, экзаменационный, высокий;
- версия базы знаний в `knowledge-base/`.

## Где хранить знания

Каноническая папка преподавателя:

`C:\!_1_WB\Скилы учитель\knowledge-base`

Сайт развёртывается из версионированного снимка `knowledge-base/` внутри проекта. После утверждения новых материалов преподавателем синхронизируйте их:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\sync-teacher-knowledge.ps1
```

Новая тема считается готовой, когда содержит источник, теорию, примеры, типичные ошибки, практику, контроль, повторение и статус проверки преподавателем.

## Локальный запуск

Требуется Node.js 22.13+ и pnpm.

```powershell
pnpm install
pnpm dev
pnpm test
```

Переменные Telegram описаны в `.env.example`. Секреты хранятся только в окружении хостинга и не входят в репозиторий.

После появления HTTPS-домена бот настраивается так:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup-telegram.ps1 `
  -BotToken $env:TELEGRAM_BOT_TOKEN `
  -PublicUrl $env:PUBLIC_APP_URL `
  -WebhookSecret $env:TELEGRAM_WEBHOOK_SECRET
```

Скрипт регистрирует команды, кнопку Mini App и webhook для `message`, `callback_query` и `pre_checkout_query`, затем проверяет установленный URL. Без реального токена, webhook и `initData` локальная сборка не считается живым Telegram-ботом.
