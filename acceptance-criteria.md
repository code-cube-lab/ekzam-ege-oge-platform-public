# Критерии готовности MVP

1. На ширине 390 px первый экран читается без горизонтального скролла, кнопки не перекрываются.
2. Гость видит позиционирование, бесплатную диагностику, методику эксперта и тарифы.
3. Кнопка «Начать диагностику» открывает кабинет ученика.
4. Free-пользователь проходит 5 вопросов и получает серверно рассчитанный результат и минимум две слабые темы.
5. Без demo-cookie `/api/coach` возвращает 401; для free/pending/expired — 403.
6. После server-side перехода в paid `/api/coach` возвращает персональный разбор.
7. После reload paid-состояние восстанавливается из HttpOnly cookie + D1, без localStorage.
8. Admin открывает кабинет преподавателя и видит демо-учеников; обычный ученик не получает teacher API.
9. Страницы `/terms`, `/support`, `/paysupport` доступны.
10. Production build, lint и тесты завершаются успешно; в консоли ключевого пути нет необработанных ошибок.
11. Платёж и внешняя AI-модель явно помечены как demo/mock до подключения реальных ключей.
