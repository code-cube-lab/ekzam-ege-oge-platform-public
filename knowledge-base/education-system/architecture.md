# Система образования «СЛОВО»

Рабочая копия архитектуры платформы. Канонический документ хранится в `C:\!_1_WB\Скилы учитель\education-system\SL0VO-EDUCATION-SYSTEM.md`.

## Ядро

`Учебное заведение -> предметная команда -> преподаватель -> подтверждённый навык -> курс -> тема -> учебная единица -> задание -> попытка -> освоение -> повторение`

Русский язык и литература — первый модуль. Сайт, Telegram, будущая PWA, пользователи, согласия, прогресс и аналитика общие для всех предметов.

## Учебный цикл

Диагностика -> тип ошибки -> короткое объяснение -> немедленное задание -> разбор -> следующий шаг -> интервальное повторение -> эскалация преподавателю.

## Роли

Ученик, родитель/законный представитель, преподаватель, методист и администратор. AI — исполнитель утверждённой логики, не самостоятельный преподаватель.

## Правило подключения преподавателя

Публичный профиль создаёт только доказательный каркас. До публикации курса нужны согласие преподавателя, интервью, образцы материалов и педагогическая приёмка.

## Правило подключения предмета

Нужны карта экзаменационных навыков, нормативные источники, диагностический банк, модель ошибок, четыре уровня, эксперты и тесты качества. Общие API и интерфейсы не дублируются.

## Защита данных

Согласие родителя для несовершеннолетнего, отдельная отметка персональных данных, минимизация, удаление профиля и российская база первичного хранения до массового запуска.
