# Product brief: «Слово»

## Цель

- Проблема пользователя: школьнику трудно понять, что именно мешает получить высокий балл, а подготовка распадается на несвязанные тесты, видео и занятия.
- Обещанный результат: за 12 минут определить слабые темы и получить понятный персональный маршрут подготовки к ОГЭ или ЕГЭ по русскому языку и литературе. Это первый предметный модуль будущей мультипредметной платформы.
- Главное действие: пройти диагностику и выполнить первое рекомендованное задание.
- Не входит в первую версию: реальная проверка ФИПИ-заданий, банковская оплата, Telegram-бот, видеозвонки, production-аутентификация школьников и подключение внешней LLM.

## Пользователи и состояния

| Состояние | Как определяется | Что видит | Что разрешено сервером |
|---|---|---|---|
| anonymous | Нет demo-cookie и серверной записи | Витрина, методика, тарифы | Публичные страницы |
| free | Серверная сессия, entitlement=`free` | Диагностика, план на сегодня, ограниченный прогресс | Сохранение диагностики, без AI API |
| invoice_pending | Entitlement=`pending` | Проверка статуса, без обещания доступа | Только чтение сессии |
| paid | Entitlement=`paid` | AI-наставник, расширенный план, полный разбор | Защищённый coach API |
| expired/refunded | Entitlement=`expired` | Причина закрытия и восстановление | Без coach API |
| admin | Серверная роль `admin` | Кабинет преподавателя и ученики | Teacher API и coach API |

## Путь пользователя

1. Публичная страница объясняет ценность и роль Елены Николаевны Михайличенко.
2. Пользователь открывает бесплатный кабинет и проходит 5-шаговую диагностику.
3. Система вычисляет прогноз и слабые темы, предлагает следующий урок.
4. Платный режим предлагается после полученной бесплатной ценности.
5. В MVP состояния оплаты переключаются в подписанном серверном демо-контуре.
6. После серверного подтверждения открывается AI-наставник.
7. При expired/refunded защищённый API снова возвращает отказ.

## Данные и интеграции

- Источник личности: в MVP анонимная demo-сессия с HttpOnly cookie; для production нужна отдельная система публичной аутентификации.
- Платёжный режим: mock/local verified; production-провайдер выбирается отдельно. Для Telegram-версии планируются Telegram Stars.
- Хранилище: Cloudflare D1, таблица demo-сессий и учебного прогресса.
- Защищённые маршруты/API: `/api/coach`, `/api/teacher`.
- Секреты и `.env.example`: `OPENAI_API_KEY`, `DEMO_MODE`, `SESSION_SIGNING_SECRET` без значений.
- Хостинг и HTTPS: OpenAI Sites / Cloudflare-compatible Worker.

## Визуальный стиль

- Источник дизайна: мастер-промпт; отдельные визуальные материалы из `!_WB` пока не предоставлены.
- Токены: тёплый молочный фон, тёмный хвойный текст, лаймовый акцент, фиолетовый для AI, коралловый для предупреждений.
- Mobile: нижняя навигация кабинета, крупные зоны касания, отсутствие горизонтального скролла, безопасная работа клавиатуры.
- Free/paid: платный режим добавляет реальные инструменты и ответы API, а не меняет только подпись.

## Проверка

- Сборка: production build, lint и unit/smoke tests.
- Браузер: desktop и mobile, диагностика, переключение состояний, AI paywall.
- Telegram live: не входит в этот MVP.
- Payment live: не входит в этот MVP; только mock/local verified.
- Ограничения: методические материалы эксперта и реальные задания должны быть загружены владельцем до учебного запуска.
