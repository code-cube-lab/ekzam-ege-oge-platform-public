## Границы опубликованной версии

- GitHub Pages размещает статический сайт, практику, локальный прогресс, черновики, родительский отчёт и бесплатный режим Mini App.
- Данные прогресса в этой версии хранятся только в браузере пользователя и не синхронизируются между устройствами.
- Статическая страница Mini App работает как честный бесплатный предпросмотр. Публичный профиль и подпись кнопки бота существуют, но живой ответ `/start` не подтверждён. Персональный Telegram-профиль, ежедневная доставка, синхронизация между устройствами и оплата требуют отдельного HTTPS-сервера, webhook и серверной проверки `initData`.
- Оплата Telegram Stars не считается проверенной без реального события `successful_payment` на сервере.
- Массовые личные сообщения, подписки и вступления в группы не выполнялись. Доска предназначена для ручного, персонального и согласованного контакта с публичными администраторами и специалистами.
- Цены на главной являются ориентирами будущего пилота, а не подтверждением подключённой оплаты или действующего тарифа.
- Репозиторий, главная, каталог `/growth/teachers/`, отдельные страницы русского и математики вернули HTTP 200. Полный публичный браузерный прогон GitHub Pages прошёл 124 из 124 сценариев без ошибок JavaScript, включая desktop, 390 px, 27 отдельных маршрутов преподавателей, 81 подробный сценарий Reels, фильтры источников, копирование, точечные ссылки и 14-дневный маршрут поиска учеников.
