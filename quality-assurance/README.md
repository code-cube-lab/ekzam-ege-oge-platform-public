# Проверка сайта ОГЭ / ЕГЭ

Эта папка связывает требования пользователя, автоматические тесты и ручную браузерную проверку.

## Установленный GitHub-навык

- Репозиторий: `openai/skills`
- Навык: `skills/.curated/playwright-interactive`
- Локальная установка: `C:\Users\GIGA\.codex\skills\playwright-interactive`
- Назначение: постоянная браузерная сессия, проверка кликов, состояний, мобильной версии и снимков экрана.

Навык не добавляет пользовательские данные и не отправляет ответы наружу. Он используется только как сценарий контроля качества.

## Быстрый запуск

1. `pnpm run qa:exam` — структура вопросов, формы ответов, отсутствие учебников и базовая адаптивность.
2. `pnpm run test` — сборка и полный регресс.
3. `pnpm run qa:browser` — полный браузерный прогон desktop + mobile со снимками в `output/qa`.

## Правило выпуска

Нельзя считать сайт готовым, если не пройдены отдельно:

- функциональный сценарий ОГЭ;
- функциональный сценарий ЕГЭ;
- ошибка и повтор похожего задания;
- мобильный экран 390 × 844;
- визуальная проверка первого экрана и экзаменационного бланка.
