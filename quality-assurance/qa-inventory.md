# Карта проверки

| Требование | Действие пользователя | Ожидаемый результат | Доказательство |
|---|---|---|---|
| Сначала выбрать экзамен | Открыть `/exam` без параметров | Видны только две крупные кнопки ОГЭ и ЕГЭ | снимок desktop + mobile |
| ОГЭ и ЕГЭ не смешиваются | Выбрать ОГЭ, затем ЕГЭ | Меняются паспорт, число заданий и длительность | DOM + снимок |
| Русский ОГЭ | Открыть вариант № 1 | 13 заданий, части 1–3, изложение и сочинение | автоматический тест + браузер |
| Русский ЕГЭ | Открыть вариант № 1 | 27 заданий, части 1–2, сочинение № 27 | автоматический тест + браузер |
| Ответ как в бланке | Открыть задание с вариантами | Варианты статичны, ответ вводится цифрами | браузер |
| Разбор после попытки | Ввести неверный ответ | Появляются теория, причина и похожее задание | браузер |
| Тетрадь ошибок | Ошибиться, открыть режим ошибок | Неверное задание сохранено; верный повтор убирает его | браузер |
| Изложение ОГЭ | Включить, поставить на паузу, продолжить и прослушать второй раз | Пауза не расходует новое прослушивание; третье воспроизведение заблокировано | браузер + вызовы аудиодвижка |
| Нет учебников 5 класса | Проверить главную и меню | Нет ссылок на `/school`, `/textbooks` и текста «5–11» | тест + браузер |
| Мобильная версия | Повторить основные шаги при 390 × 844 | Нет горизонтального скролла и обрезанных кнопок | числовая проверка + снимок |
| Практика по номеру | Открыть `/practice`, выбрать № 5 | Открывается серия задания № 5 с целью «3 верных подряд» | DOM + браузер |
| Пауза письменной работы | Начать изложение ОГЭ, включить аудио, поставить всё на паузу и обновить страницу | Текст и время сохранены, поле и аудио остановлены до продолжения | браузер |
| Серия изложений | Открыть отработку задания № 1, отправить изложение и нажать «Следующий новый текст» | Открывается следующее задание № 1 с другим авторским аудиотекстом | браузер + сравнение текста аудио |
| Отчёт родителю | После ответов открыть `/parent-report` | Видны точность, слабые/сильные темы и следующий шаг | DOM + браузер |
| Приватность открытой версии | Открыть `/director` и проверить публичные файлы | Нет выручки, учеников, списков клиентов и внутренних настроек | DOM + тест файлов + снимок |

## Исследовательские сценарии

1. Переключить ОГЭ → ЕГЭ после частично заполненного ответа: ответ должен сброситься, а карта заданий не должна сохранить чужую нумерацию.
2. Открыть «Мои ошибки» на чистом устройстве: должна появиться понятная пустая страница, а не пустой рабочий лист.
3. Ввести цифры в другом порядке там, где порядок не важен: ответ должен быть принят.
4. В задании на соответствие изменить порядок цифр: ответ должен быть отклонён.
